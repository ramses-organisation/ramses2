The namelist block `&GADGET_PARAMS` is used to configure reading initial condition snapshots in Gadget-1 or Gadget-2 format (e.g., generated by DICE or GADGET). This namelist is active when `filetype='gadget'` in `&INIT_PARAMS`.

| Variable name | Fortran type | Default value | Description |
|:---|:---|:---|:---|
| `ic_file` | `character` | `''` | Filename of the Gadget snapshot file located inside the directory specified by `initfile` (e.g. `initfile(1)`). |
| `ic_format` | `character` | `''` | Format of the Gadget snapshot file. Allowed options are `'Gadget1'` (unformatted binary with implicit block order) or `'Gadget2'` (tagged 4-byte block identifiers). |
| `ic_skip_type` | `integer array` | `(-1,-1,-1,-1,-1,-1)` | List of Gadget particle types (0: gas, 1: halo/DM, 2: disk, 3: bulge, 4: stars, 5: boundary) to skip when loading from the file (for example if gas is initialized analytically). |
| `IG_rho` | `real` | `1.0d-6` | Intergalactic medium (background) gas density floor in units of [H/cc] for cells where no SPH gas particles are mapped. |
| `IG_T2` | `real` | `1.0d7` | Intergalactic medium background gas temperature (T/mu) in [K]. |
| `IG_metal` | `real` | `0.01` | Intergalactic medium background metallicity in solar units. |
| `gadget_scale_l` | `real` | `3.085677581282d21` | Gadget unit of length in cm (default corresponds to 1 kpc). |
| `gadget_scale_v` | `real` | `1.0d5` | Gadget unit of velocity in cm/s (default corresponds to 1 km/s). |
| `gadget_scale_m` | `real` | `1.9891d43` | Gadget unit of mass in g (default corresponds to 1e10 solar masses). |
| `gadget_scale_t` | `real` | `3.15576d13` | Gadget unit of time in seconds (default corresponds to 1 Myr). |
| `ic_head_name` | `character(4)` | `'HEAD'` | Block identifier for the header block in Gadget-2 format. |
| `ic_pos_name` | `character(4)` | `'POS '` | Block identifier for coordinates in Gadget-2 format. |
| `ic_vel_name` | `character(4)` | `'VEL '` | Block identifier for velocities in Gadget-2 format. |
| `ic_id_name` | `character(4)` | `'ID  '` | Block identifier for particle IDs in Gadget-2 format. |
| `ic_mass_name` | `character(4)` | `'MASS'` | Block identifier for particle masses in Gadget-2 format. |
| `ic_u_name` | `character(4)` | `'U   '` | Block identifier for internal energy in Gadget-2 format. |
| `ic_metal_name` | `character(4)` | `'Z   '` | Block identifier for metallicity in Gadget-2 format. |
| `ic_age_name` | `character(4)` | `'AGE '` | Block identifier for stellar formation epoch/age in Gadget-2 format. |
